# Gad

Text-based game "Gad" (Russian: "Гэд") by Davarg, Nunhan, and Nikita Tseykovets (Russian: Никита Цейковец).

The game is in Russian and developed for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/?id=gad).

The game was first published on October 25, 2025.

Interactive fiction identifier (IFID) of the game: 5E0C49F4-362A-4BEE-9465-7372D61C504C

## Description

"Дрянная жизнь", - думал ты, ехав в город Гэд. Если бы ты родился в другой семье, может тебе бы никогда и не пришлось отвозить заказ Лормана (небольшую повозку, доверху забитую тканями) в этот город нищеты. Но, как всегда бывает, уже почти у города тебя ограбили и притом хорошо ударили по голове. Когда ты очнулся, тебя осенила идея, что Лорман спустит с тебя три шкуры за его товар, поэтому немедленно надо его вернуть и доставить на рынок.
